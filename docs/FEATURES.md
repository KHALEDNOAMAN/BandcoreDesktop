# Bandcore Desktop - Feature Overview

## vs Official Bandcamp
| Feature | Bandcamp | Bandcore |
|---------|----------|---------|
| Stream music | ✅ | ✅ |
| Download albums | Limited | ✅ Full |
| Last.fm scrobbling | ❌ | ✅ |
| Discord Rich Presence | ❌ | ✅ |
| AMOLED dark theme | ❌ | ✅ |
| Offline playback | ❌ | ✅ |
| Unlimited streaming | 3 plays | ✅ |
| Desktop notifications | ❌ | ✅ |
| Keyboard shortcuts | ❌ | ✅ |

## Keyboard Shortcuts
| Key | Action |
|-----|--------|
| Space | Play/Pause |
| →/← | Next/Previous |
| ↑/↓ | Volume |
| Ctrl+D | Download current |
| Ctrl+L | Toggle Last.fm |
| Ctrl+, | Settings |

## Audio Formats
Supports: FLAC, MP3 320, WAV, AAC, Ogg Vorbis
